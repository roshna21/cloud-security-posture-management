How to read this page

  • Risk score: one number per business unit. Every unpatched vulnerability and every broken security setting adds to it; serious, internet-facing and overdue items add more. Lower is better.
  • Goal line: the most risk leadership accepts for that unit. Above the line, the unit head is alerted.
  • Before is the first assessment, when nothing had been fixed. Now is the latest measurement. If "now" is 0, everything found has been fixed.
